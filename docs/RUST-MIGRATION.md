# Rust移植の対応表

v0.1.0の.NET実装とリリースは保持。配布用実装はrust/へ追加。

| 既存機能 | Rust対応 |
|---|---|
| 停止状態で起動・日本語の注意事項 | Win32ウィンドウ・明示的な有効ボタン |
| Enter改行、左右Ctrl+Enter送信 | 同じPolicyと入力列 |
| Shift/Alt/Windows付きEnter | そのまま |
| 長押し1回・途中の有効化/前面切替 | 状態機械で再変換なし |
| 通常/テンキーEnterの分離 | 独立した2つのPolicy |
| 注入無視・自己注入タグ | フラグと同じタグで除外 |
| 部分注入失敗 | Enter再送なし・受理済み部分だけ復元・停止表示 |
| 通常版Discordだけ | 前面プロセスのexe名を完全一致。失敗時は対象外 |
| 前面の再確認 | 入力直前に前面・プロセス・修飾キーを再確認 |
| Ctrl+Alt+F10 | 同じホットキー。登録失敗を画面表示 |
| 通知領域・復帰・終了 | Win32 Shell_NotifyIcon。Explorer再起動時に再登録 |
| 独自アイコン・権限昇格不要 | 同じICOとasInvoker manifestをexeへ埋め込み |
| 二重起動防止 | 旧版と同じLocal\\EnterGuard名前付きMutex |

## 検証の境界

自動テストはキー判定、入力列、部分失敗回復、プロセス名、Windows構造体と入力エンコードを対象とする。Windows CIのスモークテストは実際のUI/フック/通知領域の初期化、初期停止、有効/停止の切替、終了を確認する。Discord画面への入力やIMEの確定動作は確認しない。

Discord内部の入力欄（パスワード欄を含む）は識別しない。ログイン前に停止する必要がある。SendInput直前の前面再確認でも競合は完全には除去できない。Windowsの低レベルフックの処理時間制限は継続する。実機チェックリスト完了前はプレリリースとして配布する。
